# Create Linux User Script

This script creates a new user on a Linux system using shell scripting.

## Requirements
- Linux system
- Root/sudo privileges

## How to Run

1. Clone this repository:
```bash
   git https://github.com/Somesh1404/User-Creation-using-Script
   cd User-Creation-using-Script
```

2. Give execute permission to the script:
```bash
   chmod +x user_creation.sh
```

3. Run the script with sudo:
```bash
   sudo ./user_creation.sh
```

## What it does
- Creates a new user with a home directory
- Sets the default shell to bash
- Sets a default password
